# Oikistes
Oikistes è un gioco didattico sulla colonizzazione greca nel Mediterraneo. 

Sei l'ecista, il comandante di una spedizione navale volta alla fondazione di una nuova colonia nel Mediterraneo dell'VIII secolo avanti Cristo. La Pizia ha parlato e ora sei pronto a salpare con i tuoi compagni. Prenderai il mare e cercherai di trovare un luogo adatto per la tua nuova colonia. Le scelte che prenderai diranno come sarà organizzata la vostra nuova patria. 

Oikistes è un gioco didattico ispirato a Seedship.
